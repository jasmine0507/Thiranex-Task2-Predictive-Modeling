# Predictive Modeling Using Machine Learning

## Internship Project — Thiranex

### Project Overview
This project demonstrates supervised machine learning using a Decision Tree classifier to predict student results (Pass or Fail) from sample student performance data.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

### Project Workflow
1. Create and inspect the sample dataset.
2. Separate input features and target labels.
3. Split data into training and testing sets.
4. Train a Decision Tree classifier.
5. Evaluate model accuracy and classification metrics.
6. Visualize the confusion matrix and ROC curve.
7. Visualize feature importance.

### Dataset Features
- Study Hours
- Attendance
- Previous Score

**Target:** Student Result (Pass/Fail)

### Note
The dataset is a small, illustrative sample created for learning purposes. Evaluation results may vary and should not be interpreted as real-world student performance evidence.

### How to Run
1. Download or clone this repository.
2. Open `Task2_Predictive_Modeling.ipynb` in Jupyter Notebook.
3. Run the notebook cells in order.

### Learning Outcomes
Practiced supervised learning, model training, test-set evaluation, and machine learning visualization.
